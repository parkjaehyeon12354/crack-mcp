# 휴대폰에서 crack 커넥터 쓰기

Claude 휴대폰 앱에서 크랙 스토리를 읽고, 만들고, 고쳐서 임시저장하는 방법이다. **PC는 필요 없다.**

- 서버는 클라우드(Google Cloud Run)에서 돈다. 서버를 아직 안 올렸다면 [README의 "휴대폰에서 쓰기 → 1. Google Cloud Run에 올리기"](../README.md#휴대폰에서-쓰기-커스텀-커넥터-pc-불필요)부터 한다.
- 저장은 **임시저장까지만** 된다. 등록(공개)은 크랙 사이트에서 직접 누른다.

## 준비물

| 이름 | 생김새 | 어디서 |
|---|---|---|
| **커넥터 주소** | `https://<서버>/<비밀 키>/mcp` | 배포할 때 출력됨. 이 저장소로 PC에서 배포했다면 `~/.crack-mcp/connector-url.txt` |
| **로그인 페이지 주소** | `https://<서버>/<비밀 키>/setup` | 커넥터 주소 끝의 `/mcp`를 `/setup`으로 바꾼 것 |
| claude.ai 계정 | | 무료 플랜은 커스텀 커넥터를 **1개까지만** 추가할 수 있다 |
| 크랙 계정 | | 휴대폰 브라우저에서 crack.wrtn.ai에 로그인할 수 있어야 한다 |

> 두 주소에는 비밀 키가 들어 있다. **비밀번호처럼 다룬다.** 메신저나 캡처로 남에게 보내지 않는다.

---

## 1. 크랙 로그인을 서버에 연결 (처음 한 번)

서버가 내 크랙 계정에 접근하려면 로그인 토큰이 한 번 필요하다. 휴대폰 브라우저의 **북마크** 하나로 넘긴다.
이 북마크는 크랙 탭에서 토큰을 읽어 내 서버로만 보낸다. 다른 곳으로는 보내지 않는다.

1. 휴대폰 브라우저로 **로그인 페이지 주소**를 연다.
2. **코드 복사** 버튼을 누른다.
3. 북마크를 만들고, 그 주소를 복사한 코드로 바꾼다.
   - **안드로이드 크롬**: 아무 페이지에서 ⋮ → ☆(북마크 추가) → 화면 아래에 뜨는 **수정** → 이름 `crackmcp`, **URL 칸을 지우고 코드를 붙여넣기** → 저장
   - **아이폰 사파리**: 공유 버튼 → **북마크 추가** → 저장. 그다음 북마크 목록(책 아이콘) → **편집** → 방금 만든 북마크 → 이름 `crackmcp`, **주소를 코드로 바꾸기** → 완료
4. 새 탭에서 **crack.wrtn.ai**에 로그인한다.
5. **그 크랙 탭에서** 북마크를 실행한다.
   - **안드로이드 크롬**: 주소창에 `crackmcp`를 입력하고, 아래 목록에 뜬 **북마크(별 아이콘)를 누른다**
   - **아이폰 사파리**: 북마크 목록을 열고 `crackmcp`를 누른다
   - 주소창에 코드를 직접 붙여 넣으면 브라우저가 `javascript:` 부분을 지워서 동작하지 않는다. 꼭 북마크로 실행한다.
6. 로그인 페이지로 돌아오면서 **"연결 완료!"** 가 뜨면 끝이다. 그 탭은 닫아도 된다.

그 뒤로는 서버가 토큰을 알아서 갱신한다. **14일 안에 한 번이라도 쓰면** 다시 할 필요가 없다.

## 2. Claude에 커넥터 추가 (처음 한 번)

휴대폰 앱보다 **휴대폰 브라우저의 claude.ai**에서 하는 게 확실하다. 앱에서 커넥터를 직접 추가하는 기능은 아직 베타다.
메뉴 이름은 Claude 버전에 따라 조금씩 다를 수 있다.

1. 휴대폰 브라우저로 **claude.ai**에 로그인한다.
2. 메뉴(☰) → 아래쪽 **내 이름(프로필)** → **설정(Settings)** → **커넥터(Connectors)**.
   "맞춤 설정(Customize) → 커넥터"로 나오는 버전도 있다.
3. **커스텀 커넥터 추가(Add custom connector)** 또는 **+** 를 누른다.
4. 다음처럼 입력한다:
   - 이름: `crack`
   - URL: **커넥터 주소** 전체 (`.../mcp`로 끝나는 주소)
   - 고급 설정(OAuth Client ID, Secret): **비워 둔다**
5. **추가(Add)** 를 누른다.

웹에서 추가하면 Claude 휴대폰 앱에도 같은 커넥터가 나타난다. 안 보이면 앱을 완전히 껐다 켠다.

## 3. 채팅에서 쓰기

1. Claude 앱에서 새 채팅을 연다.
2. 입력창 옆 **+** 또는 **도구 버튼** → 목록에서 **crack**을 켠다.
3. 평소처럼 말한다. 처음 도구를 쓸 때 허락을 물으면 **허용**한다.

### 이렇게 말하면 된다

| 하고 싶은 것 | 예시 |
|---|---|
| 목록 | "크랙 내 스토리 목록 보여줘" |
| 내용 보기 | "'아아' 스토리 프롬프트랑 첫 메시지 보여줘" |
| 고치기 | "'아아' 첫 메시지를 이걸로 바꿔서 임시저장해 줘: …" |
| 새로 만들기 | "크랙에 새 스토리 만들어 줘. 제목은 …, 프롬프트는 …, 첫 메시지는 …" |
| 키워드북·스탯·엔딩 | "'아아'에 키워드북 '학교' 추가해 줘. 키워드는 학교, 교실 / 정보는 …" |
| 제한 확인 | "크랙 키워드는 몇 자까지야?" |

- 저장하고 나면 Claude가 **크랙 빌더 링크**를 준다. 그 링크를 열어 내용을 확인하고, 괜찮으면 사이트에서 **등록하기**를 누른다.
- 글자 수 제한을 넘으면 저장하지 않고 "이름: 31자 (허용 2~30자)" 같은 목록을 보여 준다. 그만큼 줄여 달라고 하면 된다.
- PC Claude Code의 `/crack` 명령은 휴대폰에는 없다. 휴대폰에서는 그냥 말로 하면 된다.

## 4. 다시 로그인해야 할 때

Claude가 **"크랙 로그인이 필요해요"** 와 함께 로그인 페이지 주소를 보여 주면, 14일 넘게 안 써서 토큰이 끊긴 것이다.
**1번의 4~6단계만** 다시 하면 된다. 만들어 둔 북마크는 그대로 쓴다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 커넥터 목록에 crack이 없다 | claude.ai 웹에서 추가됐는지 확인. 앱을 완전히 껐다 켠다 |
| 커넥터 추가 시 연결 실패 | URL이 `/mcp`로 끝나는지, 앞뒤 공백 없이 전체가 들어갔는지 확인. 주소가 틀리면 서버는 404만 돌려준다 |
| 무료 플랜인데 추가 버튼이 막힘 | 무료 플랜은 커스텀 커넥터 1개까지. 다른 커넥터를 지우거나 유료 플랜 |
| "크랙 로그인이 필요해요" | 4번 |
| 북마크를 눌러도 아무 일 없음 | 크랙 탭에서 눌렀는지, 크랙에 로그인돼 있는지 확인. 주소창에 직접 붙여 넣으면 안 된다 |
| "crack.wrtn.ai 에 로그인한 상태로…" 경고 | 크랙이 아닌 페이지에서 북마크를 눌렀거나, 크랙에서 로그아웃된 상태 |
| "크랙이 이 토큰을 거부했어요" | 크랙에서 로그아웃 → 다시 로그인 → 북마크 다시 누르기 |
| 첫 응답이 몇 초 늦다 | 정상이다. 안 쓰는 동안 서버가 꺼져 있다가 켜지는 시간이다 |
| 저장했는데 사이트에 안 보인다 | Claude가 준 빌더 링크로 열기. 등록 안 한 스토리는 내 작품 목록에 안 나오고 빌더 링크로만 보인다 |

## 보안

- 북마크는 **정확히 `crack.wrtn.ai` 페이지에서만** 동작한다. 다른 사이트에서 누르면 경고만 띄우고 아무것도 보내지 않는다.
  북마크 코드에 비밀 키가 들어 있어서, 다른 사이트에서는 실행되지 않게 막아 둔 것이다.
- 비밀 키는 주소에 들어간다. Claude 커스텀 커넥터는 "인증 없음"과 OAuth만 지원하고, 키를 헤더로 보내는 방식이 없기 때문이다.
  그래서 Google Cloud 요청 로그에 주소(비밀 키 포함)가 남는다. 이 로그는 **Google Cloud 프로젝트 소유자만** 볼 수 있다.
  여러 사람이 쓰는 서버로 만들 거라면 OAuth를 붙여야 한다.
- 커넥터 주소나 로그인 페이지 주소가 새어 나갔다고 생각되면 **비밀 키를 바꾼다.**
  서버의 `CRACK_SECRET`을 새 값으로 업데이트하고(README 배포 명령 참고), claude.ai에서 커넥터를 지운 뒤 새 주소로 다시 추가한다.
  1번의 북마크 코드에도 주소가 들어 있으니, 새 로그인 페이지에서 코드를 다시 복사해 북마크를 고친다.
- 서버는 크랙에 **임시저장까지만** 한다. 등록·공개·삭제 기능은 없다.
